# Enterprise Risk Management Plan
**Course:** CYBR 521 — Info Assurance & Risk Assessment | Hood College  
**Author:** Karnelius Sindhu

## Project Overview
Developed a comprehensive enterprise risk management plan for a simulated organization aligned to NIST Cybersecurity Framework (CSF) and NIST Risk Management Framework (RMF).

## What This Plan Covers
- Asset identification and classification
- Threat identification and likelihood assessment
- Vulnerability analysis and impact scoring
- Risk prioritization using likelihood x impact methodology
- Security control selection aligned to NIST SP 800-53
- Risk mitigation strategies across technical and administrative domains
- Security roles and responsibilities
- Compliance requirements and best practices

## Frameworks Applied
- NIST CSF: Identify, Protect, Detect, Respond, Recover
- NIST RMF: Risk categorization, control selection, implementation
- NIST SP 800-53: Security control mapping

## Skills Demonstrated
- Risk assessment and analysis
- Threat modeling
- Security control framework mapping
- Compliance documentation
- Risk mitigation planning
